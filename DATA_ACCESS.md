# Data access

## Current status

This repository has been initialized for the RetinaXpert research materials. Actual images, annotation records, source mappings, and split manifests are pending upload.

## Original image sources

The original fundus-image datasets are identified in Tables 1 and 2 of the manuscript. Add the corresponding official source URLs, dataset versions, and access instructions to `metadata/` when preparing the release.

## NoSplit and Split

- `NoSplit/`: the existing unsplit collection and associated records, or a link to its archive.
- `Split/`: the existing partitioned collection and associated records, or links to its archives.
- `metadata/`: the mapping between study image identifiers, original dataset identifiers, labels, and the fixed experimental partitions.

Use the exact partitions associated with the reported experiments. Retain the original filenames or supply an explicit identifier mapping.

## Distribution

Where redistribution is permitted, images may be released through a suitable data repository and linked from this repository. Where images must be obtained from the original provider, document that access route instead.

The original dataset licenses and terms of use apply to the images. Any restrictions affecting the released annotations or metadata should be identified specifically, with the corresponding access procedure.
